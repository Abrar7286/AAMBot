# AAMBot
My Final year project. is a three wheeled robot which is given instructions to follow some orders as assigned. An autonomous robot which can take certain orders from humans and take some actions. This all is done with some basic functionalities for the robot. 
The robot will be used for different platforms for different objectives. But in general
  •	A coloured line path to detect and follow
  •	Implement Graph having nodes representing different positions.
  •	Signals be produced by nodes.
  •	Detect and make a queue of signals.
  •	Response to signals in FCFS manner.
  •	Learn the paths to adopt a shortest route from one node to other.
  •	Save the addresses of nodes in databases.
  •	Detect hurdles in its way.
  •	Robot shall not travel to the nodes outside of its range (it only has access to the nodes of which it has address/location).
  •	It shall not go to any next node and/or will not go back to the previous node unless it does not get a networking signal. 
  •	Robot shall not hit or collapse when an obstacle is detected in its way. 
  •	Robot shall avoid using the longest path.
  •	Robot should avoid getting into a loop
